# 设计工具 · 获取 Windows 安装包指南

这是一个本地运行、MasterGo 风格的设计工具（不用动任何代码）。

## 你想拿到的东西
一个**可以双击直接安装**的 `.exe` 安装包，装好后是一个独立桌面程序。

> 说明：`.exe` 安装包必须在 **Windows 环境**里编译。
> GitHub 提供免费的 Windows 云服务器会自动编译，你只需要完成一次"上传代码"。
> 整个操作**全程网页点击，不需要写代码**。

---

## 三步拿到你的 .exe

### 第 1 步：注册 GitHub 并建一个空仓库（第一次需要，10 分钟）
1. 打开 https://github.com/signup 注册账号（免费，用邮箱）。
2. 登录后，点击右上角 **+** → **New repository**。
3. 仓库名字随便填（比如 `design-tool`），其他都保持默认，点 **Create repository**（创建）。
4. 创建后你会进入一个空白仓库页面，先保持这个页面不动。

### 第 2 步：把项目文件传上去（第一次需要，一次搞定）
1. 在刚创建的空仓库页面，点 **Add file** → **Upload files**（上传文件）。
2. 把下面这个完整的项目文件夹拖进上传框：
   > `design-tool` 文件夹（里面包括 `src`、`src-tauri`、`.github`、`package.json` 等所有内容）

   > 注意：
   > - **不要**传 `node_modules`、`dist`、`src-tauri/target` 这几个文件夹（它们会自动生成）。
   > - 如果你的电脑没有这个文件夹，我这边可以先把整个项目打包成一个 zip 发给你下载，你再解压上传。
3. 页面下方点 **Commit changes**（提交）。

### 第 3 步：云服务器自动编译，下载安装包
1. 代码上传后，GitHub 会自动开始构建（右上角出现一个黄色的 ✓）。
2. 点顶部菜单 **Actions** → 点 **Build Windows Installer** 那条运行记录。
3. 等右侧出现绿色 ☑（构建成功，约 3–6 分钟），在页面底部 **Artifacts** 区域点击下载：
   > `windows-installer`
4. 解压后得到类似 `设计工具_0.1.0_x64-setup.exe` 的文件，**双击它 → 一路点"安装"**。
5. 装好后，开始菜单里就会出现 **设计工具**，点击即可使用。

之后每次我改好功能，你只要把这几个文件再替换上传一次，就会自动重新出新的安装包。

## 常见问题
- **没有 design-tool 文件夹？** 找我要，我会把项目打成 zip 发给你。
- **双击系统提示"未知发布者"？** 正常，个人免费签名会这样，点"仍要运行"即可。
- **想在本机（Windows）自己构建？** 可以，但需要装 Node.js + Rust，麻烦些；用上面云端构建最省事。
